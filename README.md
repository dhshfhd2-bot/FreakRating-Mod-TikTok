# Мод: TikTok (полноценный оверлей)

Это оригинальный мод TikTok: окно поверх игры, открывается по **F8**.
Файл один — `tiktok-phone.js`, он работает в главном процессе лаунчера.

## Как поставить

1. Скачай `tiktok-phone.js`.
2. Положи его в папку:
   ```
   FreakRating-Client-Mods\mods\main\tiktok-phone.js
   ```
   Папка `main` внутри `mods` создаётся автоматически при первом запуске.
3. Перезапусти `start.bat`.

F8 — открыть/закрыть TikTok. Чтобы удалить — удали файл из `mods\main`.
