# Мод: TikTok

F8 открывает TikTok в отдельном окне поверх игры.

## Что копировать

**Только один файл: `mods/tiktok.js`**

Папка `optional/` — старая версия с оверлеем для сборки из исходников. Обычно она не нужна.

## Как поставить

1. Скачай `mods/tiktok.js`.
2. Положи в папку `mods` рядом со `start.bat`:
   ```
   FreakRating-Client-Mods\mods\tiktok.js
   ```
3. Перезапусти `start.bat`.

Чтобы удалить — удали `tiktok.js` из папки `mods`.
